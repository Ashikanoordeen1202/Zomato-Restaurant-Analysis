# Zomato Restaurant Analysis | Power BI

## Project Overview
This project analyzes restaurant data to understand global restaurant distribution, customer ratings, pricing, cuisine popularity, online delivery, and table booking availability.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Dashboard Features
- Total restaurants, countries, cities, average rating, average cost, and votes
- Restaurant distribution by country and city
- Rating distribution analysis
- Price range analysis
- Online delivery and table booking analysis
- Top 10 cuisines
- Geographic restaurant distribution map
- Interactive Country, City, and Price Range slicers

## Files Included
- Power BI dashboard (.pbix)
- Restaurant dataset (.xlsx)
- Dashboard screenshot (.png)

## How to Use
1. Download the `.pbix` file and dataset.
2. Open the report in Microsoft Power BI Desktop.
3. Refresh the data source if necessary.
4. Use the slicers to explore restaurant insights.
